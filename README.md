# Procedural Terrain Builder

An editor-only procedural terrain generation, carving, and baking system for Godot 4+.

## Features
- Dynamic, real-time heightmap updates in the editor.
- AAA-grade slope and height-based blending.
- Contrast-based triplanar mapping to prevent texture stretching on cliffs.
- Organic grass patchiness and macro-color variation.
- Support for vertical sedimentary rock strata on cliffs.
- Real-time inspector synchronization (updates splatmap on the fly).
- Support for custom user textures without forced tinting.

## Installation
Clone or copy the `addons/procedural_terrain_builder` folder into your Godot project's `addons/` directory. Enable the plugin in Project Settings -> Plugins.
